# LincScales

Your Business. Scaled.

LincScales is a Next.js App Router website for performance marketing and AI automation. The current build is a preview foundation: it includes the public homepage, pricing, custom plan request form, client onboarding flow, private admin dashboard foundation, and self-service AI platform foundation.

## Preview in Codespaces

```bash
npm install
npm run dev -- --hostname 0.0.0.0
```

Open the forwarded port `3000` in the Ports panel, or visit `http://localhost:3000` in the Codespace browser.

Routes:

- `/` public homepage
- `/request` custom advertising plan request
- `/onboarding` customer onboarding foundation
- `/admin` private admin dashboard foundation
- `/platform` self-service AI chatbot platform foundation

## Validation

```bash
npm run build
```

Payments, authentication, CRM integrations, and AI model connections are intentionally not active in this preview.
